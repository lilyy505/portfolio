# My Personal Website

- **About Me:** A brief introduction and overview of my professional background.
- **Experience:** A detailed timeline of my past roles and work history.
- **Projects Showcase:** A gallery highlighting my recent work and personal projects.
- **Dynamic LinkedIn Feed:** A custom integration that reads from a local JSON file to render my recent posts directly on the site.
- **Interactive UI:** Features active navigation highlighting as you scroll through the page sections.

## Tech Stack

- HTML / CSS
- Vanilla JavaScript
- JSON (for post data management)
