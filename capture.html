Publish a LinkedIn post

One-time setup

1. Drag this button to your bookmarks bar:

Send to site

2. Create a GitHub token so this page can commit for you: go to Fine-grained tokens → Only select repositories → portfolio → Repository permissions → Contents: Read and write. Paste it below.

Stored in this browser only (localStorage, on your own domain — never on LinkedIn's). Scoped to this one repo, so the worst it can do is edit your portfolio. Revoke anytime on GitHub.

How to post

Post on LinkedIn → open that post on its own page (click its timestamp, or ⋯ → Copy link to post) → click Send to site in your bookmarks bar. You'll land back here with everything filled in, you check it over, and hit Publish.

Review

Edit anything before it goes live — this is your last look.
